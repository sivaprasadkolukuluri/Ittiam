# Partner logos

Drop the official logo files here, named exactly like this:

| Partner     | File name         |
|-------------|-------------------|
| Google      | `google.webp`      |
| Meta        | `meta.webp`        |
| Dolby       | `dolby.webp`       |
| Netflix     | `netflix.webp`     |
| Samsung     | `samsung.webp`     |
| Sony        | `sony.webp`        |
| Harman      | `harman.webp`      |
| Continental | `continental.webp` |

The strip uses these exact names. To swap in a sharper SVG later, keep the same name with `.svg` and update the `src` in `ittiam/index.html`.

## What works best

- **SVG**, from each company's press or brand page. If SVG isn't available, use a PNG at least 600px wide with a transparent background.
- **The horizontal wordmark** (the full name, as in the Google logo), not the app icon.
- **A version that reads on a dark background.** If a brand's logo is black (Dolby, Sony, Harman), add the white or reversed version instead. A black logo would disappear on our navy.
- Trim empty space around the logo, so all eight sit at the same visual size.

The strip shows every logo in muted grey by default and switches to the original colours on hover. You only need to add the full-colour originals.
